# YOLO Test

This repository contains tests and experiments with the YOLO (You Only Look Once) object detection algorithm.

## Features

- Sample YOLO models and configurations
- Test scripts for image and video detection
- Results and performance metrics

## Getting Started

1. Clone the repository:
  ```bash
  git clone https://github.com/your-username/yolo-test.git
  cd yolo-test
  ```

2. Install dependencies:
  ```bash
  pip install -r requirements.txt
  ```

3. Run a test:
  ```bash
  python test_yolo.py --image sample.jpg
  ```

## Folder Structure

- `models/` - Pretrained YOLO models
- `scripts/` - Test and utility scripts
- `results/` - Output images and logs
